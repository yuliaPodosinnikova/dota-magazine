# Dota 2 Secret Shop Simulator 

Консольный симулятор внутриигрового магазина предметов из Dota 2 на языке Python. 

## Описание проекта
Проект представляет собой интерактивную лавку артефактов. Игрок может зарабатывать золото с помощью симуляции фарма крипов, покупать предметы и собирать их в своем инвентаре.

## Функционал
- Просмотр лавки: Вывод реальных предметов (Iron Branch, Blink Dagger, Divine Rapier) с их ценой и бонусами.
- Покупка с проверкой баланса: Система проверяет, хватает ли у героя золота, и вычитает нужную сумму.
- Механика Фарма: Возможность быстро подзаработать золото, нажав кнопку симуляции фарма.
- Сохранение прогресса: Инвентарь игрока и баланс золота автоматически сохраняются в `JSON`-файлы и не сбрасываются после перезапуска программы.

## Архитектура проекта
- `main.py` — запуск интерактивного CLI меню.
- `src/shop.py` — бизнес-логика (расчет стоимости, добавление в инвентарь, фарм).
- `src/database.py` — работа с файлами сохранения (`hero_save.json`) и базой товаров (`shop_items.json`).

## Инструкция по запуску
Вызовите команду в терминале внутри папки проекта:
```bash
python main.py
```
